# Employee Management System

A menu-driven **Employee Management System** developed using **Python** that allows users to efficiently manage employee records. The project follows **Object-Oriented Programming (OOP)** principles and uses **File Handling** for persistent data storage. It provides a simple command-line interface for performing employee management operations.

---

## 📌 Features

- ➕ Add Employee
- 👀 View Employee Records
- 🔍 Search Employee
  - By Employee ID
  - By Name
  - By Department
- ✏️ Update Employee Details
- ❌ Delete Employee
- 📊 Employee Dashboard
  - Total Employees
  - Highest Salary
  - Lowest Salary
  - Average Salary
- 🔃 Sort Employees
  - Salary (Ascending & Descending)
  - Name (A-Z & Z-A)
- 📁 Persistent Data Storage using File Handling
- 📄 Export Employee Records to CSV
- ✅ Input Validation
- ⚠️ Exception Handling

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Employee-Management-System.git
```

2. Open the project folder

```bash
cd Employee-Management-System
```

3. Run the program

```bash
python main.py
```
